# First power-on checklist

- [ ] Photograph robot, model labels, rear head/tablet, charge connector.
- [ ] Confirm charger rating **28.6 V, 8 A** and exact Pepper locking plug with seller.
- [ ] Inspect for physical or battery damage; stop on heat, odour or swelling.
- [ ] Charge per original manual; record charger LED and battery indications.
- [ ] Release emergency stop per manual and attempt normal boot.
- [ ] Record screen, LED sequence, spoken messages and physical movement.
- [ ] Identify hardware revision and NAOqi version **before any reset**.
- [ ] Attach to isolated test network and obtain IP.
- [ ] Test documented owner credentials or defaults without brute-force.
- [ ] If access succeeds, export applications/config and back up.
- [ ] If locked, request approved specialist recovery rather than blind flashing.
- [ ] Test supervised text-to-speech then limited gesture from an external PC.
