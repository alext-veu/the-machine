# Pepper // The Awakening website

Static, responsive, standalone project microsite (no build dependencies) for GitHub Pages. Entry point: `docs/index.html`. Uses an interactive CSS perspective illustration rather than a full WebGL 3D mesh; movement is pointer-reactive and there is an accessible reduced-motion fallback.

## Publishing

In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /docs → Save**. This setting requires repository administrator access and is **not available in the current connector**. For a private repository, GitHub plan/org settings determine whether Pages is available. Once published, expected URL (not verified live): `https://alext-veu.github.io/the-machine/`.

The existing root Vite app remains unchanged. The website is a standalone educational concept; it does not connect to robot hardware.
